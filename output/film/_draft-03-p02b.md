## 【本场 coverage】p02b 追问赝品

**本场要完成的空间**：把「赝品」从货架（东侧）带到收银台（西侧靠南墙）——这是本场唯一一次道具位移，也是分支 p02b 与 p02a 的物理分界。空间关系必须让观众看清：货架在东、柜台在西、门在南，主角始终在货架一侧，程知遥从货架走到柜台并靠住台角。

**本场要完成的人物**：
- 主角：从「翻看物证」到「追问人」，判断权在他手上，越问越逼近。
- 程知遥：从「收笔」到「给信息」到「靠台等问」，全程不劝、不安慰，只递事实。

**本场必须出现的插入**：
1. 赝品背面三特征（无压纹、蓝油墨、浅铅笔痕）——一次给全。
2. 程知遥把笔收回外套内袋——动作不快，是她「不再报价」的收束。
3. 她左手无名指旧疤——只在选择反馈里出现，不提前给。

**本场必须出现的运镜**（至少五种里的两种以上，且各有触发）：
- 缓推：主角问「你猜的？」时，靠近他的压力。
- pan：程知遥指货架、从左到右划半圈时，重新分配注意力。
- tracking：她走两步到收银台，跟住。
- locked-off：赝品背面插入、收笔插入、选择停住——硬验收。
- tilt：从货架第三到第五排空位升到东北角坏灯，交代「她说的假货」与「坏灯」同处一个空间。

**本场必须出现的次级选择停住**：p02b-a / p02b-b 各一镜，手与唱片停在台面上，可暂停给 UI。

**轴线**：门—货架—柜台锁死。主角在货架一侧（东），程知遥从货架走到柜台（西），两人不越轴。p02a 机位不复用：本场主角侧用货架排间侧后方、低角度；程知遥侧用柜台后方纵深与过肩。

### SH-p02b-01　背面三特征
- **节点 / 分支 / 时长**：p02b / trunk / 3 秒
- **戏剧动词**：发现
- **画面**：画框几乎被一张黑胶唱片背面填满，唱片由主角左手托住，拇指压在标签边缘。标签纸偏米黄，边缘有一道浅铅笔痕，从标签左下角向中心划出约两厘米，笔迹断续。编号印在标签右上，油墨是偏亮的蓝，比正常印刷蓝更跳、更浮，像后补。整张标签没有压纹，纸面平得发闷，光从左上打来，在标签表面留一层薄反光。背景是虚掉的深棕木货架与货架托架，暗到只剩轮廓。
- **景别 / 角度 / 焦距意图**：大特写 / 俯视约 30 度 / 长焦隔离，浅景深
- **机位**：货架前，主角左手正上方偏左，高度约在主角胸口，看向唱片背面，在轴线东侧
- **运镜**：锁定。因为这是硬验收插入——三特征必须一次给全，任何运动都会让观众漏掉铅笔痕。
- **调度**：主角左手托唱片，右手未入画；拇指从标签边缘轻压一下，唱片不动，只是让标签反光变一下
- **资产**：PROP-record-fake、DETAIL-fake-no-emboss、DETAIL-fake-ink-blue、DETAIL-fake-pencil-mark、SET-shelf-row-3、CHAR-player
- **起始状态 → 结束状态**：唱片在主角左手、背面朝上；结束仍在左手、背面朝上，拇指位置不变，反光角度略变
- **声音**：环境底噪；无拟音；无对白
- **剪在**：拇指压标签边缘的动作点
- **验收**：画面里必须同时看清「无压纹」「蓝油墨编号」「浅铅笔痕」三样，缺一不可
