# 煤山倒计时·朕只剩七天

## 一、共同主线与结局

**所有人都会走的外部主线：** 崇祯十七年三月十三到三月十九。李自成从居庸关到北京城下，你只有七天。每一天，局势都往下掉一格，你能做的事越来越少。

- **三月十三**：醒来，知道七天。居庸关破，京营点卯五万实到八千。
- **三月十四**：钱。国库空，勋贵不肯捐，兵要发饷。
- **三月十五**：南迁之议。李明睿上疏请你南下，太子走不走。
- **三月十六**：吴三桂还在宁远，调他入关就要放弃关外。守城部署。
- **三月十七**：李自成到了城下。太监杜勋出城谈判，回来带话。
- **三月十八**：城内有人开门。兵变、内应、火光。
- **三月十九**：城破，或没破。你走向煤山，或走向别的。

**四个结局：**

**「守城」**——满足「我镇住了」的欲望。你成了这个朝廷真正怕、也真正服的明君。世界：城没破，李自成退到城外扎营，但你身后没有一个人敢靠近。得到：一个还活着的大明。失去：你身上最后那点人味。只有这里才有的场面：你站在城头，风很大，你想找个人说句话，回头看，所有人都在三步之外跪着。走进条件：威 >= 7。

**「南迁」**——满足「我活下来了」的欲望。你成了半个皇帝，大明裂成两半。得到：命，和南边半个朝廷。失去：北边半壁，和「大明是一个整体」这件事。只有这里才有的场面：船过江，太子问你，父皇，我们还算大明吗。走进条件：已送走太子，且心 >= 7。缺「太子已走」就不开。

**「开门」**——满足「我换一个活法」的欲望。你放弃了皇帝这个身份。得到：一个你不知道会怎样的明天。失去：龙袍、名分、和所有还指望你的人。只有这里才有的场面：你脱下龙袍，走出宫门，守门的兵不认识你，问你是谁。走进条件：见过使者。

**「煤山」**（退路，失败结局）——满足「至少我自己选怎么死」的欲望。你输得干净，但你没跪。得到：一棵树，和一个人的陪。失去：大明，和你所有的果断。只有这里才有的场面：王承恩跪在你身后，树上挂着你昨天写的字，风把它吹得响。走进条件：始终可进。

## 二、人物

**你（朱由检 / 那个理科生）**——你睁眼就在龙床上，脑子里有一整张崇祯十七年的表。你要的：不吊死在煤山上。你里面要的：证明「讲道理」这件事，在这个世界行不行得通。能力：会算、会拆、会问为什么。缺点：你把人也当成可以算的东西，算到某一步你会发现，最贵的那笔账你算不出。底线：不杀说真话的人。你会反复出现在每一场，因为你是皇帝，所有人都得来见你。

**王承恩（司礼监太监，六十岁）**——眼下的生活：替你看住这个宫里所有人，包括你自己。表面要的：你活着。里面要的：你活得像个人，不像他见过的那几个皇帝。能力：知道谁在撒谎，知道宫里每条暗道。缺点：太忠，忠到不敢拦你。底线：你。他反复出现，因为他是唯一不跟你要东西的人。他会留下，除非你先把他当工具用。

**周皇后（你的皇后，三十五岁）**——眼下的生活：把后宫的钱挪出来给守城的兵，自己减膳。表面要的：你别太累。里面要的：你把心里的事说给她听，而你从来不说。能力：看人极准，一句话点破你在装。缺点：把「懂事」当成了活法。底线：太子。她反复出现，因为家是这个死局里唯一不跟你讲利害的地方。她会走，如果你每次都把她当成一个需要处理的麻烦。

**魏藻德（内阁首辅，四十岁）**——眼下的生活：两边下注，一边给你写诏书，一边给李自成留门。表面要的：保住官位。里面要的：赌你是输的那个。能力：说话滴水不漏，能把任何事说成两可。缺点：贪，且怕死。底线：没有。他反复出现，因为他是这个朝廷的镜子——你动刀，他跪；你心软，他上。他会留到最后一刻，除非你先杀了他。

**李明睿（左中允，五十岁）**——眼下的生活：写了一封请你南迁的疏，压了三天不敢上。表面要的：你别死在这。里面要的：有人肯听真话。能力：敢说别人不敢说的。缺点：说了真话，不会挑时候。底线：他的疏。他反复出现，因为他就是那道底线的化身。他会留下来挨你的刀，除非你让他走。

**太子朱慈烺（十六岁）**——眼下的生活：读书，抄《资治通鉴》，他抄的那一页正好是「唐玄宗幸蜀」。表面要的：父皇别生气。里面要的：你别把他当成一件必须转移的东西。能力：记得住事，会问。缺点：太像你，也爱算。他反复出现，因为他是你这盘棋里唯一的「以后」。他会走，如果你送走他；会留下来，陪你到最后。

## 三、会变的事

**1. 这本书在玩什么：** 七天做减法。用杀伐镇住这个朝廷，还是保住还有人肯跟你；做明君，还是做人。

**2. 为什么是这两件事：** 它们互相拉扯。你每果断一次，威就涨，心就掉——而心掉到底，威也就撑不住了，因为没人肯替一个没人爱的人打仗。

**3. 两件会变的事：**

- **威 6｜0–12｜** 朝堂听不听你的、兵还调不调得动、城守不守得住。杀人立威、压下异议、当众定罪 +；示弱、被顶撞、朝令夕改 −。
- **心 5｜−3–12｜** 还有没有人肯为你死、你还是不是人。护住一个人、说真话、守信 +；杀无辜、当众羞辱、绝情 −。

**4. 做下的事：**

- 斩过提督｜开「威压朝堂」这条路
- 知道谁吃了空饷｜手里多一个把柄
- 太子已走｜开「南迁」这条路
- 压下南迁｜关「南迁」这条路
- 杀了李明睿｜**破底线**：王承恩从此不再对你说真话
- 见过使者｜开「开门」这条路
- 斩了使者｜关「开门」这条路，威 +2

**5. 选择对照：**

```
朝会 · 当场斩了京营提督｜威 +2｜心 -1｜记下：斩过提督
朝会 · 不动声色，密查空饷｜威 0｜心 +1｜记下：知道谁吃空饷
南迁 · 准李明睿，先送太子走｜威 -1｜心 +2｜记下：太子已走
南迁 · 当朝斥退，绝口不谈南迁｜威 +1｜心 -1｜记下：压下南迁
南迁 · 杀了李明睿立威｜威 +3｜心 -3｜记下：杀了李明睿（破底线）
城下 · 见杜勋，听他开价｜威 -1｜心 +1｜记下：见过使者
城下 · 斩杜勋，首级挂上城墙｜威 +2｜心 -2｜记下：斩了使者
```

**6. 结局条件：**

- **守城**：威 >= 7。缺了，就只能往煤山走。
- **南迁**：需「太子已走」，且心 >= 7。缺「太子已走」不开；心不够，开了也走不成。
- **开门**：需「见过使者」。斩了使者就不开。
- **煤山**：始终可进，退路。
- 终局只列当前开着的门。只剩一扇就直接走进去，不摆假按钮。

**走三条路验证：**
- 一路果断：斩提督 → 压下南迁 → 斩使者。威 6+2+1+2=11，心 5-1-1-2=1。威够，守城开；心太低，南迁、开门都不开。落到守城或煤山。✓
- 一路摇摆：暗查 → 送太子 → 见使者。威 6+0-1-1=4，心 5+1+2+1=9。威不够守城，但太子已走、心够，南迁开。✓
- 很早决绝：斩提督 → 杀李明睿 → 斩使者。威 6+2+3+2=13（顶到12），心 5-1-3-2=-1。破底线，王承恩不再说真话。守城开，但终局里没有一个人靠近你。✓

## 四、分支的形状

- **朝会（斩 / 查）：当场汇合。** 选完这一场就回主线，差异留在「谁知道什么」——你斩了人，满朝都知道你动刀；你暗查，只有你和王承恩知道。
- **南迁（送太子 / 压下 / 杀李明睿）：延迟汇合于「城下」。** 从三月十五到三月十七，太子在不在、李明睿死没死，会让这两天的戏不一样。汇合点是「李自成的兵到城下」——这件事谁都躲不过。
- **城下（见 / 斩使者）：延迟汇合于终局。** 它决定「开门」这扇门开不开，几乎是半条不汇合的路。
- **终局：** 只给当前开着的门。

**持续影响（写正文时每场先看这条）：**

```
持续影响 ·「太子已走」这条路
从「南迁」到「城下」之间：
- 第三章起，宫里少一个人。周皇后不再问你「烺儿呢」
- 第四章调吴三桂时，你没有「以后」这个选项压着，下决定更快
- 第五章城下谈判，你可以说「朕没有退路」，是真话

持续影响 ·「杀了李明睿」这条路
从「南迁」到终局：
- 王承恩不再主动进言。你问他，他只答「是」「奴婢不知」
- 朝会上再没有人上疏说真话，只剩魏藻德那种话
- 终局里，没有人会替你收尸，除了王承恩——他还是会来
```
