# 角色资产模式契约

本文件定义各 Mode 的输入、默认模型、输出和验收门槛。模型专属写法由 adapters 中的对应文件决定。

## 共享身份账本

新角色至少登记：

- 明确成年人、性别表达和可选的已确认族裔或地域外观。
- 脸型、下颌、颧骨、眼形眼色、眉、鼻、唇。
- 自然肤色与底色、头发颜色、长度、纹理、密度和分缝。
- 体型、肩胯比例、四肢比例和默认站姿。
- 永久纹身及位置、疤痕、美人痣、固定穿孔等身份标记。
- 默认中性表情。

妆面、美甲和可替换首饰在 Mode 1 锁定。标志性常戴配饰在 Mode 0 登记，在 Mode 1 视觉锁定。胸像外的永久标记只能记入账本，不能声称标准身份卡已经视觉验证。

用户没有提供的字段不是默认值。若缺失会影响身份锁定，用一个合并问题追问；若不影响本步，直接省略。禁止用“自然发色”“标准鼻型”“普通眉形”“非夸张嘴唇”等模糊默认补全。

## Mode 0：定脸与标准身份卡

进入条件：没有稳定身份参考的新角色。

三条公开模型路线：

1. Nano Banana Pro 直接建立标准身份卡。
2. GPT Image 2 生成非权威候选脸；用户选定唯一候选后，用 Nano Banana Pro 标准化。
3. Midjourney V8.2 生成非权威候选脸；用户选定唯一候选后，用 Nano Banana Pro 标准化。

候选阶段只探索脸、肤色、头发、克制妆面和当前胸像可见标记，不写体型，不加入复杂微观皮肤或长否定清单。公众人物或偶像参照必须先转成用户确认的可见五官、妆发和气质，Prompt 不写姓名。

标准身份卡：

- 默认模型：Nano Banana Pro。
- 输入：纯文字规格，或唯一获选候选图。
- 输出：脸占主体的胸像，3:4，2K，一张。
- 女性用黑色细肩带基础上衣；男性用黑色罗纹背心；中性人物用黑色圆领上衣。
- 中性基础修饰，不带 Look 妆面或可替换首饰；只保留身份型穿孔。
- 18% 中性灰无缝背景，均匀低对比度 Flat Grade。
- 输出经用户批准后才成为唯一权威身份卡。

Nano Banana Pro 不可用时，默认交付该步骤的 Nano Banana Pro Prompt。只有用户明确接受模型变化后，才可用能力满足的 GPT Image 2 工具制作替代身份卡，并把模型变化写进锁定卡。

## Mode 1：服装定妆

进入条件：已有用户批准的标准身份卡。

- 默认模型：Nano Banana Pro。
- 输入：权威身份卡和完整 Look。
- 完整 Look 包含服装、鞋、首饰、配件、妆面、发型或发饰、美甲、可见永久标记。
- 默认输出：3:4，2K，一张全身图；手和鞋完整可见，轻微转角，中性表情。
- 背景：18% 中性灰无缝背景，Flat Grade。

复杂服装可用两步路线，但只有工具确认支持双参考时才能进入：

1. 先生成普通模特的完整 Look。
2. R1 为服装、妆发、美甲和姿势；R2 为权威人物身份。把 R2 人物替换进 R1 造型。

每套新 Look 都必须单独获得用户批准的服装基准图。

## Mode 1B：造型细节卡

进入条件：全身图里某个已经批准的细节太小，或用户主动要求局部资产。

- 默认模型：GPT Image 2。
- 主参考：批准的 Mode 1 服装基准图；工具支持时可再附权威身份卡。
- 每张只做一个区域：美甲或戒指、手链、纹身、耳饰、项链、鞋、服装工艺。
- 默认输出：1:1；纵向区域可用 3:4；2K，一张。
- 细节卡只放大已批准设计，不能替 Mode 1 修正错误，也不能替代身份卡或服装基准图。

脸是主体时转 Mode 3。

## Mode 2：三格角色表

进入条件：已有批准的 Mode 1 单张服装基准图。

- 默认模型：Nano Banana Pro。
- 输入：批准的服装基准图；需要时附权威身份卡并明确职责。
- 输出：16:9，2K 或 4K，一张横图，三个等宽竖格。
- 左格：ghost-mannequin 正面全身，从肩部以下展示完整服装和身体比例，保留正常头顶留白，不是画面裁头。
- 中格：带头背面全身，展示完整后发、服装背部、下摆和鞋。
- 右格：从头顶上方至锁骨的紧胸像，是整张图唯一清晰正脸锚点。
- 三格使用同一 Look、体型、肤色、材质颜色、背景和 Flat Grade。

必须在工具参数或界面控件中显式设置 16:9，并在执行后回读。若工具无法设置或核对，进入 PROMPT_ONLY。

## Mode 3：高精度面部特写

进入条件：用户需要脸部、肩上或胸像细节；它不重建身份。

- 默认模型：GPT Image 2。
- 输入：权威身份卡。
- 输出：3:4，质量 high 或当前工具最接近的高细节档，一张。
- 裁切：chest-up、shoulders-up 或 forehead-to-collarbone。
- 可锁定眼色、妆面、唇部、耳饰、服装上缘、可见身份标记、视线和微表情。
- 使用中性灰背景和克制柔和人像光，不追加 Flat Grade 长块。

非脸部细节转 Mode 1B；权威身份需要重建时回 Mode 0。

## Mode 4：两参考图换装

进入条件：工具确认可以同时附加两张参考图，并能明确各图职责。

- 默认模型：Nano Banana Pro。
- R1：服装、鞋、首饰、配件、美甲和姿势来源。
- R2：人物身份来源，控制脸、骨相、肤色、基础头发身份和永久标记。只有 R2 本身是已批准全身参考时才控制体型与身体比例；否则使用另行锁定的文字体型规格，不得从胸像推断。
- 默认输出：3:4，2K，一张完整全身灰底图。
- 只换人物身份，不重新设计 R1 造型，不让 R1 的脸污染 R2 身份。

参考顺序不可颠倒。工具只能附一图时必须进入 PROMPT_ONLY。

## 共同验收

- 人物身份、体型、肤色和永久标记与当前权威资产一致。
- 服装、妆发、美甲、配饰只来自已批准 Look。
- 手脚、鞋、领口、背部和局部细节满足当前 Mode 的可见范围。
- 候选、权威身份卡、服装基准和衍生资产状态没有越级。
- 实际模型、参考图职责、画幅、尺寸、数量和 Prompt 已回读或明确标注为未执行。
